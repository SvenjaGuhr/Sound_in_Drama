# Sound in Drama
Repository to the Sound in Drama Paper

Guhr, Svenja / Pagel, Janis / Reiter, Nils. "What Does Drama Sound Like?" Workshop on Computational Drama Analysis, 2025.

This work will be presented at the DraCor Summit Workshop on Computational Drama Analysis takes place on Wednesday, 3 September 2025.
More information on DraCorSummit 2025: https://summit.dracor.org.

Our slides can be found [here](https://github.com/SvenjaGuhr/Sound_in_Drama/blob/main/20250903_Sound_in_GerDraCor.pdf).

A preprint of our article can be found in the conference reader: "Conference Reader: Second Workshop on Computational Drama Analysis (Berlin, 03.09.2025)", doi: [10.5281/zenodo.16814034](https://doi.org/10.5281/zenodo.16814034).

A page providing interactive supplementary visualizations can be found [here](https://svenjaguhr.github.io/sound-in-drama). The static figures in the article correspond to the interactive versions, which allow hovering over individual data points to inspect play titles, years, and genre information.
